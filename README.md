# YouTube Creator Earnings Calculator

##  Project Overview

The **YouTube Creator Earnings Calculator** is a beginner-friendly Python project that estimates a creator's monthly and yearly earnings based on the number of monthly views and CPM (Cost Per 1000 Views). It also categorizes the creator's channel level and performance using simple conditional statements.

This project is designed to practice basic Python programming concepts without using advanced features such as functions, classes, or file handling.

---

## Features

- Enter YouTube channel name
- Enter total subscribers
- Enter monthly views
- Enter CPM (Cost Per 1000 Views)
- Calculate estimated monthly earnings
- Calculate estimated yearly earnings
- Display creator level
- Display channel performance

##  How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or any Python IDE.
4. Run the program:

```bash
python youtube_earnings_calculator.py
```
